Frameworks#

Sou um desenvolvedor que utiliza bastante frameworks para acelerar o processo — de forma mais específica o RbxUtils do Sleitnick e o ProfileService.

frameworks.lua
-- Frameworks utilizados para acelerar o desenvolvimento
local RbxUtil       = require(RbxUtil)      -- Sleitnick
local ProfileService = require(ProfileService) -- salvamento de dados
O que esses frameworks fazem

Eles são criados para acelerar o processo de desenvolvimento. Muitos facilitam o input, o gerenciamento client/server, a segurança em geral, o salvamento de dados, as interfaces e muitas outras vantagens.
